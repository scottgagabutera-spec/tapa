01 — Principles

Every decision runs through these ten.

01

Trustworthy

Everything Gagara does — every pixel, every word, every interaction — must make both parties feel completely safe. We are the vault, not just the interface.

02

Mathematically logical

Every rule in Gagara has a reason. Every condition maps cleanly to an outcome. There are no grey areas in the logic — only clear, auditable, deterministic flows.

03

Encrypted without compromise

End-to-end encryption on every deal, every message, every audit log. We never store plaintext. Security is architecture, not a feature layer added later.

04

Modern

Gagara looks and feels like it was built today, for tomorrow. No legacy UI patterns. No skeuomorphic banking aesthetics. Clean, fast, decisive interfaces.

05

Premium

Every touchpoint communicates that Gagara is world-class. Premium is not about price — it is about the care in every detail, from typography to notification copy.

06

Exceptional user experience

A freelancer who just completed their first job should feel the release of funds like a satisfying click. Every flow is designed for the emotional outcome, not just the technical one.

07

Uniquely Gagara

The Deal Connector. The glass vault metaphor. The locked-but-visible funds. These belong to Gagara. Every brand element should be instantly recognisable as ours alone.

08

Consistent

One design language. One voice. One logic. Whether a user opens the app in Manila or London, on a flagship or a budget device, the Gagara experience is identical.

09

Mobile-first

Every screen, every component, every flow is designed for a thumb first — then scaled up. Desktop is a bonus. The phone is the product. Always mobile, always responsive.

10

Giant's vision

We are not building a small tool. We are building global financial infrastructure. Every decision — from architecture to brand — is made as if Gagara will serve 100 million people. Because it will.

The mark — concept

Three connected nodes on a horizontal axis. The two outer circles represent the two parties — Payer and Receiver. The line and central node represent the live Deal — the current running between them. The moment all three are filled is the moment The Link closes and funds are locked. The mark works at 16px. It works on a billboard. It works in dark and light. That is the standard.

Gagara
Programmable escrow for everyone. Lock funds, confirm conditions, release with trust.
Status: In Development Stack: Next.js · TypeScript Protocol: Interledger Open Payments Version: 0.1.0
What is Gagara?

Gagara is a transparent, programmable escrow platform where funds are locked and visible to both parties in real-time. Neither the payer nor the receiver can access the funds unilaterally — release only happens when agreed conditions are met, confirmed by both sides.

Built on the Interledger Open Payments protocol, Gagara enables instant, interoperable fund releases across currencies and payment methods — from bank accounts to mobile wallets to stablecoins.

Three deal modes
  • Personal — P2P informal agreements, freelancers, small transactions
  • Business — SMB contracts, supplier agreements, service deals
  • Enterprise — Large multi-milestone contracts, multi-party, API-driven
The Deal Connector

Every deal begins with a unique Deal Code (e.g. GGR-4829-KXMT). The payer creates the deal and shares the code. The receiver enters or scans it. The moment both sides connect — The Link closes. Funds lock. Both parties can see the balance in real-time. Neither can touch it alone.

Payer creates deal → Deal Code generated → Shared via text / QR / @handle
Receiver enters code → Preview shown → Accepted
⚡ LINKED — funds lock, deal goes live
Tech stack
  • Next.js 14 (App Router) + TypeScript
  • Interledger Open Payments API
  • Vercel (hosting + edge functions)
  • Supabase (database + auth)
  • Tailwind CSS
